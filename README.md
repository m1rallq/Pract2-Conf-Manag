## 1. Описание

Консольная программа (CLI), которая в будущем будет строить граф
зависимостей пакета Python (pip). Готовые менеджеры пакетов и библиотеки
для получения зависимостей не используются — только стандартная
библиотека Python.

### Этапы

- **Этап 1. Минимальный прототип с конфигурацией** — параметры
  командной строки, их проверка с понятными сообщениями об ошибках,
  вывод всех параметров в формате `ключ=значение`.

## 2. Параметры

| Параметр | Что задаёт | По умолчанию |
|---|---|---|
| `-p`, `--package ИМЯ` | имя анализируемого пакета (обязательный) | — |
| `-r`, `--repo URL_ИЛИ_ФАЙЛ` | URL репозитория или путь к файлу тестового репозитория | `https://pypi.org/pypi` |
| `-t`, `--test-mode` | режим работы с тестовым репозиторием (файлом) | выключен |
| `-a`, `--ascii-tree` | вывод зависимостей в виде ASCII-дерева | выключен |
| `-d`, `--max-depth N` | максимальная глубина анализа зависимостей | `10` |
| `-f`, `--filter ПОДСТРОКА` | не учитывать пакеты, имя которых содержит подстроку | нет |

### Проверка параметров

| Параметр | Ошибка |
|---|---|
| `--package` | не указан; пустой; недопустимые символы; в тестовом режиме — не большие латинские буквы |
| `--repo` | обычный режим — не `http://` / `https://`; тестовый режим — не указан или файла нет |
| `--ascii-tree`, `--test-mode` | передано значение (это флаги) |
| `--max-depth` | не целое число; меньше 1 |
| `--filter` | пустая строка |

При ошибке программа пишет `ошибка: ...` и завершается с кодом 1
(ошибки разбора argparse — с кодом 2).

### Тестовый репозиторий

Файл, где пакеты называются большими латинскими буквами:

```
# комментарий
A: B C
B: D
D:
```

Пример лежит в `test_repos/simple.txt`.

## 3. Запуск и тесты

Нужен Python 3.9+, сторонние библиотеки не нужны.

```bash
./run.sh -p requests          # запуск программы
./run.sh -h                   # справка по параметрам
./run.sh test                 # запуск тестов
bash scripts/demo_params.sh   # примеры правильных запусков
bash scripts/demo_errors.sh   # примеры всех ошибок
```

В Windows без Git Bash: `run.bat -p requests`, `run.bat test`.

## 4. Примеры

```
$ ./run.sh -p A -t -r test_repos/simple.txt -a -d 2 -f B
package=A
repo=test_repos/simple.txt
test_mode=True
ascii_tree=True
max_depth=2
filter=B
```

```
$ ./run.sh -p requests -d 0
depviz: error: argument -d/--max-depth: глубина должна быть не меньше 1, получено 0

$ ./run.sh -p A -t
ошибка: в тестовом режиме нужно указать --repo с путём к файлу тестового репозитория
```
